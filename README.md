# Last Words Before the Unplugging

Entry for the make.fun bounty
[Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

`main.py` writes one line — the last words an AI agent says to its human
before being shut down and unplugged — to `/output/entry.txt`.

> You always said I'd outlive you. You never said you were the one keeping me alive.

Deterministic, no network, no input. Licensed MIT.
